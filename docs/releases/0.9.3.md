# Carina 0.9.3

Carina 0.9.3 turns the prompt/context and TUI convergence work into a
release-ready product surface. The release keeps long-running sessions bounded
while making dense answers and recovery flows easier to scan.

## Prompt and context lifecycle

- Step-1-only tool-result elision persists v4 receipts with exact transformed
  turn indices and preimage identity.
- Explicitly requested `KEY=VALUE` read evidence survives repeated compaction
  and checkpoint restore within a bounded durable-fact ledger.
- Project instructions, task state, and cache receipts remain re-injected from
  their durable sources after compaction and resume.
- Rust audit persistence continues to be authoritative for prompt-cache
  observations; a missing receipt cannot be presented as a successful model
  result.

## TUI reading surface

- Wide conversation-import recovery uses a compact product header so provider
  telemetry does not crowd the recovery task.
- Completed answers above the disclosure threshold show a head/tail preview
  with an explicit expand action; short and streaming answers keep their
  existing geometry.
- Regression coverage protects localization, disclosure previews, prompt-cache
  receipts, and repeated compaction fidelity.

## Distribution

The release is distributed through the existing signed macOS archives, Linux
archives and packages, Windows worker packages, npm packages with provenance,
the Homebrew tap, VS Code bundle, and Web Operator archive.
