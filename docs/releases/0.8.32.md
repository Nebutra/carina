# Carina 0.8.32

Operator-visible remainder after 0.8.31. Listing a workspace should not
time out inside `target/` or `Library`, and a Grok isolation refusal
should not tell you to run `grok models`.

## Highlights

- `carina-scan` and `carina-grep` skip ignored directories instead of
  walking them and discarding the files afterward. Home directories and
  Rust `target/` trees no longer hit the 30s toolchain timeout.
- Grok Build isolation inspect/safety failures say to switch models or
  open Details. They no longer prescribe `grok models`.
- Chinese prompts such as “创建一个新项目 / 写一个…” count as repo work
  for project-instruction loading.

## Upgrade notes

- Restart an active workspace runtime after upgrading so its daemon, kernel
  service, native tools, and TUI all load 0.8.32. Carina does not interrupt
  active tasks automatically. Reopen the TUI after the daemon epoch changes.
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
