# Carina 0.8.34

Operator-visible remainder after 0.8.33. A short or colloquial question
should get a short, situated answer — not a product tour, feature matrix,
or option menu. The host does not classify operator phrases to splice
policy back in.

## Highlights

- PRODUCT CAPABILITY BRIEF is out of the live constitution. Intent is meta:
  answer this message in this conversation; infer the unspoken ask.
- `prompt_mode` is a mode switch. converse does not dump AGENTS.md.
  build/plan always load project instructions. explore never does.
- `done` ends the turn after the ask is met. It is not a personality.
- Identity stays Carina by Nebutra (云毓智能).

## Upgrade notes

- Restart an active workspace runtime after upgrading so its daemon, kernel
  service, native tools, and TUI all load 0.8.34. Carina does not interrupt
  active tasks automatically. Reopen the TUI after the daemon epoch changes.
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
