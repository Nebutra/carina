# Carina 0.8.39

Operator-visible remainder after 0.8.38. Every Grok Think still spawned a
new `grok agent stdio` process after inspect-skip, and a follow-up that
named no new object (`你有什么看法`) was treated as a fresh menu.

## Highlights

- Grok ACP/`stdio` is persisted on the reasoner. Turn 2+ sends
  `session/prompt` on the same pipes and does not `exec` a new `grok`.
  Close, cancel, and a failed Think still terminate the child.
  Inspect-once, empty tools, no-yolo, and JSON ReAct stay. Grok
  prompt-cache kind remains `none`.
- Session dialogue is framed as the live conversation. A follow-up that
  names no new object is about the topic already on the table.

## Upgrade notes

- Restart an active workspace runtime after upgrading so its daemon, kernel
  service, native tools, and TUI all load 0.8.39. Carina does not interrupt
  active tasks automatically. Reopen the TUI after the daemon epoch changes.
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
