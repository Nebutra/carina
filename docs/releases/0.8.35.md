# Carina 0.8.35

Operator-visible remainder after 0.8.34. A follow-up like “对此你怎么看”
must see the previous answer in this session. A markdown table in chat must
not paint into the scrollbar gutter.

## Highlights

- Each new run hydrates prior operator prompts and `done.summary` from the
  same session into the model view. The latest pair is pinned so compact
  cannot drop it before the first Think. The audit log is not copied.
- Conversation markdown tables are unboxed (header, hairline, aligned
  columns). Sharp `┌┬┐` boxes stay on `/changes`. Wrap clips so CJK cells
  cannot overflow the reading column.
- List markers in answers use muted, not the interaction accent.

## Upgrade notes

- Restart an active workspace runtime after upgrading so its daemon, kernel
  service, native tools, and TUI all load 0.8.35. Carina does not interrupt
  active tasks automatically. Reopen the TUI after the daemon epoch changes.
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
