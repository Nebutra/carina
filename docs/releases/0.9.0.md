# Carina 0.9.0

Carina 0.9.0 closes the audited harness gaps around governed tool
consumption and adds a native browser-computer surface without weakening the
capability kernel.

## Highlights

- Durable background model jobs expose bounded `job.list`, `job.wait`, and
  `job.cancel` handles scoped by root lineage, session, workspace, and tenant.
- `read` supports bounded UTF-8 line ranges with explicit partial provenance;
  structured tool failures now provide stable recovery guidance.
- `git.status`, `git.diff`, and `git.log` provide typed, bounded, read-only
  repository evidence with hostile Git configuration disabled.
- Native Chromium browser tools provide isolated managed profiles, bounded
  accessibility snapshots, typed actions, tabs, captures, stale-reference
  recovery, upload staging, download quarantine, and explicit attach approval.
- Proactive remains default-off, read-only, single-slot, transcript-isolated,
  and now has deterministic policy/versioned canary and p95 evidence.
- The protocol, Go/Python/TypeScript SDKs, CLI, Web Operator, and local docs
  expose the same governed contracts.

## Security and compatibility

- Browser navigation and request origins use the existing SSRF-safe network
  policy. Page content, dialogs, downloads, and screenshots are untrusted.
- Browser attach never scans ports and never exposes raw CDP, JavaScript
  evaluation, cookies, storage, or console execution.
- High-impact browser actions pause immediately before their external effect;
  uploads require explicit file-read and transmission approval.
- Existing 0.8.x sessions and run-store rows are normalized compatibly. Legacy
  synchronous spawn and SDK session methods remain supported.

## Upgrade

Restart the daemon after upgrading and let active tasks reach a terminal state.
Use `CARINA_BROWSER_PATH` only when automatic Chromium discovery is unsuitable;
leave `CARINA_BROWSER_ATTACH_ENDPOINT` unset unless an operator explicitly
approves attach mode. The release is distributed through the signed archives,
Debian/RPM packages, npm packages, Homebrew tap, VS Code bundle, and Web
Operator archive.
