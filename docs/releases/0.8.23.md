# Carina 0.8.23

Harness honesty remainder after 0.8.22. This version makes operator surfaces
tell the truth about no-op compression, Grok JSON-only routes, and HITL
presets, and lands the remaining composer and roster slices.

## Highlights

- Large composer pastes stay chipped, slash typos are tolerated, and
  `@path:12-40` attaches a ranged excerpt instead of the whole file.
- `carina context *` and doctor say `engine=noop` when no bytes change.
  Long-session compaction remains `Transcript.compact`.
- `read skill://review` aliases the `/review` slash command and tells the
  model not to retry the missing skill. High/xhigh/max Grok think stays at
  360s on the default 180s budget.
- Grok and other non-Anthropic routes label prefix cache `none`. Anthropic
  Messages adapters still attach cache breakpoints.
- `/agents` is a read-only roster from `agent.view`. `/plugins` lists the
  local extension inventory and never calls `plugin.run`.
- `/approval-mode` names `read-only`, `agent`, and `accept-edits` presets
  over existing product modes. Session profiles are unchanged.
  `/always-approve` stays an explicit verb.

## Upgrade notes

- Restart an active workspace runtime after upgrading so its daemon, kernel
  service, and TUI all load 0.8.23. Carina does not interrupt active tasks
  automatically.
- Named HITL presets do not rewrite the session permission profile. Start a
  new session if you need `read-only`.
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
