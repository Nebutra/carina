# Carina 0.8.10

Patch release on the 0.8 line. Focus: honest model availability on the model
picker before submit.

## Highlights

### Model health status on the model page

- `model.list` now attaches per-route `status` / `status_reason` from daemon
  retry governance (circuit breaker and recent rate-limit failures).
- Status codes: `ready`, `rate_limited`, `circuit_open`, `probing`,
  `auth_error`, `unavailable`.
- The model picker shows a localized badge for non-ready routes (for example
  限流 / 熔断中) in the list and detail pane.
- Selecting an unusable model soft-blocks with a clear notice instead of
  opening a conversation that fails immediately on submit.

## Upgrade notes

- Restart `carina-daemon` and relaunch the TUI after upgrade so inventory
  health reflects the new fields.
- Circuit / rate-limit status is in-memory for the running daemon: it appears
  after recent failures and clears on daemon restart.
- Standalone: `carina update`.
