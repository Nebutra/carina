# Carina 0.8.6

Patch release on the 0.8 line. Focus: import official Claude Code / Claude Max
OAuth through CC Switch, plus faster release CI.

## Highlights

### Official Claude OAuth via CC Switch

- CC Switch Claude profiles without an API key (e.g. **官方**) can import the
  local Claude Code OAuth access token from macOS Keychain (or credential
  files) as a Bearer credential.
- Loopback `ANTHROPIC_BASE_URL` proxies are rewritten to
  `https://api.anthropic.com/v1` for these OAuth tokens.
- Profiles remain non-importable when no local Claude Code login exists.

### Release workflow speed

- Tag workflow splits a fast contract `validate` from the full
  `validate-suite` so platform builds start earlier.
- Rust workspace cache on Darwin/Linux packaging jobs.

## Upgrade notes

- Restart `carina-daemon` after upgrade so CC Switch re-detects with OAuth.
- In the provider list, open **官方** (or your Claude OAuth row) and import
  once; then choose a model (default is the profile model such as
  `claude-opus-5`; live `/models` may expand the list).
- Standalone: `carina update`. Homebrew: `brew update && brew upgrade carina`
  after the release workflow updates the tap.
