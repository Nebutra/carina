# Carina 0.8.28

Operator-visible remainder after 0.8.27. This version keeps failure cells in
one language.

## Highlights

- Localized failure reasons no longer append an English tail onto a complete
  translated sentence. Grok handshake and isolation details map to existing
  copy. English locales still keep unknown clauses.
- `carina-patch` crate docs describe the shipped Zig native apply path
  instead of leftover Phase 0/1 wording.

## Upgrade notes

- Restart an active workspace runtime after upgrading so its daemon, kernel
  service, and TUI all load 0.8.28. Carina does not interrupt active tasks
  automatically. Reopen the TUI after the daemon epoch changes.
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
