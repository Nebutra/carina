# Carina 0.8.26

Operator-visible remainder after 0.8.25. This version tells the TUI when a
session goal pauses, instead of only updating daemon state.

## Highlights

- Live `GoalChanged` events with `status=paused` reuse the existing
  `GoalPaused` notice. An open `/goal` overlay refreshes from `goal.get`.
- Goal pause stays off the transcript. Replayed catch-up events do not
  repeat the notice. Sessions without a goal stay silent.

## Upgrade notes

- Restart an active workspace runtime after upgrading so its daemon, kernel
  service, and TUI all load 0.8.26. Carina does not interrupt active tasks
  automatically. Reopen the TUI after the daemon epoch changes.
- After Esc or Ctrl-C, the notice reads that the goal paused. Resume with
  `/goal resume` or re-arm unattended continuation with `goal.set`
  (`auto_continue: true`).
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
