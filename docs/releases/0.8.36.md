# Carina 0.8.36

Operator-visible remainder after 0.8.35. Rewinding to a prompt must keep the
conversation before that prompt, and a failed history branch must not look
like the session was erased.

## Highlights

- History fork sends `last_task_id` (the daemon also accepts `last_run_id`).
  A run without a checkpoint walks back to the last durable boundary instead
  of failing on the latest Grok error.
- A failed branch exits history selection and restores the draft and
  transcript. The notice still names the error.
- Forked sessions project parent dialogue through the fork boundary in
  `session.items`, so the TUI still shows the earlier turns.

## Upgrade notes

- Restart an active workspace runtime after upgrading so its daemon, kernel
  service, native tools, and TUI all load 0.8.36. Carina does not interrupt
  active tasks automatically. Reopen the TUI after the daemon epoch changes.
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
