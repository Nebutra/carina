# Carina 0.8.2

Patch release on the 0.8 line. Focus: dialogue-first TUI density and honest
operator-facing model/runtime feedback.

## Highlights

### Dialogue density (visual-density W1)

- Intent-first tool rows (V001) and success-read collapse language (V002):
  `Read ×N · path…` with title-only collapsed groups.
- Successful edits start **collapsed**. Create-only diffs show a file card
  (path, `+N · new file`, short line-numbered preview) instead of a full green
  `+` dump. Expand restores the review window.
- Assistant content-type channel: internal action JSON stays suppressed
  (`tool=done` → summary); whole-body JSON objects/arrays render as pretty
  markdown `json` fences — no business-field allowlists.

### Model stream reliability and failure voice

- Streaming HTTP no longer uses a wall-clock `Client.Timeout` over the SSE body.
  Header timeout + idle timeout apply; mid-body budget exhaustion is **not**
  auto-retried (explicit `execution.retry` remains the escape hatch).
- Operator-facing reasoner failures replace `modelrouter` / `Client.Timeout`
  stacks in ExecutionFailed reasons. Technical detail stays on RoutingOutcome.

### Honest context window for managed proxies

- Routes such as `ccswitch-codex-managed-proxy/gpt-5.6-sol` resolve context
  windows via catalog alias (openai/azure/…) instead of the 32k fallback.
- Footer `est.` remains only for true fallback estimates.

### Final-turn contract

- Interactive `done.summary` must be plain-language operator prose (short
  markdown allowed), not a nested JSON completion payload.

### `carina update` operator UX (also on tip)

- Human-readable phases instead of `channel=… current=…` log lines.
- TTY download progress bar; plain mode under `CI` / `CARINA_UPDATE_PLAIN`.
- Quiet one-line brand marker; restart hint remains explicit after install.

### Status labels

- `degraded` → partial completion copy; bare `unknown` maps to ready instead of
  “unknown status (unknown)”.

## Upgrade notes

- Restart long-running `carina-daemon` after upgrade so CLI, TUI, and daemon all
  advertise the `0.8.2` runtime contract.
- Standalone: `carina update`. Homebrew: `brew update && brew upgrade carina`
  after the release workflow updates the tap.
