# Carina 0.8.16

TUI product release. Converges runtime truth, reading geometry, review
workflows, and failure recovery into a quieter terminal experience.

## Highlights

### Runtime truth without footer noise

- Idle conversations no longer reserve routine status rows. Active, queued,
  waiting, paused, failed, and notice states use an adaptive zero-to-two-row
  chrome above the bottom-anchored composer.
- Running and Next model routes stay distinct, including provider and reasoning
  effort. Activity elapsed time is independent from the whole run clock.
- Paused runs block conflicting submissions and history actions while remaining
  explicitly resumable or cancelable.

### Stable reading and interaction geometry

- Transcript wrapping, rendering, scrolling, paging, scrollbar input, block
  actions, and failure actions now share one centered reading axis.
- Unicode, ASCII, no-color, compact, and comfortable modes retain the same
  semantic pointer coordinates and preserve terminal-owned backgrounds.
- Scrollbar click, drag, paging, and wheel ownership are covered across narrow
  and wide terminal layouts.

### Review and recovery workflows

- Plan Review supports focused approval, revision, anchored comments, keyboard
  navigation, and bounded responsive layouts.
- Fullscreen patch review preserves transaction identity, file and hunk detail,
  verification state, and rollback confirmation.
- Model-aware failure recovery offers bounded retry and route repair actions
  without exposing internal identifiers as transcript noise.

### Visual density and symbols

- Typed semantic transcript cells, persisted density modes, reduced-motion
  behavior, and live Unicode/ASCII symbol previews now share one production
  renderer and golden-frame contract.
- English and Simplified Chinese layouts are verified at the product width
  matrix, including narrow-terminal degradation.

## Upgrade notes

- Restart the current workspace runtime after upgrading so the daemon, kernel
  service, and TUI all use the 0.8.16 protocol surface.
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
