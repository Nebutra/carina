# Carina 0.8.25

Operator-stop remainder after 0.8.24. This version makes Esc and Ctrl-C pause
the session goal, and names the residual UX and visual-density contracts as
release iron gates.

## Highlights

- Soft interrupt now pauses an active session goal with the same WAL as
  `goal.pause`. Sessions without a goal still pause the run only.
- `execution.cancel` pauses that goal too. Operator-cancelled runs never
  count as auto-continue failures and never submit another continuation.
- `make residual-ux-gate` and `make visual-density-gate` are named
  `release-preflight` gates. CI runs residual-ux after the kernel build.

## Upgrade notes

- Restart an active workspace runtime after upgrading so its daemon, kernel
  service, and TUI all load 0.8.25. Carina does not interrupt active tasks
  automatically. Reopen the TUI after the daemon epoch changes.
- After Esc or Ctrl-C, inspect `/goal`. Resume with `/goal resume` or
  re-arm unattended continuation with `goal.set` (`auto_continue: true`).
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
