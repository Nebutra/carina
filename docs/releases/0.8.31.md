# Carina 0.8.31

Operator-visible remainder after 0.8.30. Daily chat should answer a greeting
instead of searching the repo, and recovered or collapsed turns should not
leave garbage in the document.

## Highlights

- Interactive sessions default to converse mode. `hi` finishes with `done`
  instead of inspecting the workspace. Build remains available for explicit
  implementation work and plan approval.
- Project instruction files load on build/plan or repo-work messages, not
  greetings. TASK and transcript stay out of the prompt cache prefix.
- The Grok Build adapter follows Carina JSON ReAct. It no longer labels the
  request as non-instructional data while asking for tool JSON.
- Parallel list/read/search is allowed only after the turn needs workspace
  evidence.
- Retry-in-flight and already-settled retry failures leave the reading
  column. Collapsing a tool clears wrap remnants from the unread gutter.
- Code-intelligence index progress is progress, not a `code intel error`.

## Upgrade notes

- Restart an active workspace runtime after upgrading so its daemon, kernel
  service, and TUI all load 0.8.31. Carina does not interrupt active tasks
  automatically. Reopen the TUI after the daemon epoch changes.
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
