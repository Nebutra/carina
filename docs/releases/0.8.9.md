# Carina 0.8.9

Patch release on the 0.8 line. Focus: reasoning effort selection for CC Switch
Claude / Codex live models.

## Highlights

### Reasoning effort for CC Switch models

- `ccswitch-claude-*` and `ccswitch-codex-*` models now publish native
  reasoning effort ladders (`low`…`max` for adaptive Claude; OpenAI-style
  ladder for Codex/TDS).
- The model picker can Tab / ← → cycle effort after choosing a model, instead
  of showing only “default reasoning” with an empty control.

## Upgrade notes

- Restart `carina-daemon` and relaunch the TUI after upgrade.
- Standalone: `carina update`.
