# Carina 0.8.3

Patch release on the 0.8 line. Focus: product-grade `carina update` operator UX.

## Highlights

### `carina update` dialogue UX

- Replaces `channel=… current=… target=… install=…` log lines with phased
  operator copy: header, download, verify, install, done.
- TTY download progress bar (bytes + optional total); plain mode under `CI` or
  `CARINA_UPDATE_PLAIN=1`.
- Install path abbreviated with `~/` when under the home directory.
- Quiet one-line brand marker (`◆ Carina update` on TTY); no multi-line ASCII banner.
- Restart hint remains explicit after a successful install.

## Upgrade notes

- Restart long-running `carina-daemon` after upgrade so CLI, TUI, and daemon all
  advertise the `0.8.3` runtime contract.
- Standalone: `carina update`. Homebrew: `brew update && brew upgrade carina`
  after the release workflow updates the tap.
