# Carina 0.9.2

Carina 0.9.2 hardens the prompt and context pipeline used by long-running
agent sessions. The release focuses on explicit provider behavior, bounded
context growth, and preserving operational intent across compaction and
resume boundaries.

## Prompt and cache boundaries

- System instructions are assembled as named sections with an explicit
  stable/dynamic boundary instead of an undifferentiated prompt blob.
- Direct OpenAI requests use a stable prompt cache key, while Anthropic cache
  receipts cover only the system sections that are actually marked cacheable.
- Cache telemetry reports provider-observed reads and writes. A local prefix
  hash is never presented as proof of a provider cache hit.
- Cache observations are canonical `PromptCacheObserved` events in event
  schema `0.3.3`; audit persistence failure stops the model result from being
  published instead of silently dropping the release evidence.
- Tool descriptors are projected for the active session so inactive schemas
  do not consume every request by default.

## Context lifecycle

- Compaction uses proactive pressure forecasting and topic boundaries before
  the hard context limit, with bounded durable facts for user steering,
  failures, changed paths, next actions, and explicitly requested read markers.
- Step-1-only tool-result elision emits a v4 compaction receipt with exact
  transformed turn indices and preimage identity, even when no model summary
  is needed.
- Project instructions and the active task are rebuilt after compaction and
  checkpoint resume instead of relying on a lossy conversation summary.
- Memory injection is relevance-ranked and budgeted; subagents receive a
  bounded task packet and return summaries rather than full transcripts.
- Context diagnostics expose budget pressure, prompt sections, cache receipts,
  and warm-up-adjusted cache SLO status.

## Verification

- Regression coverage includes provider cache receipts, prompt stability,
  tool projection, instruction re-injection, bounded memory, subagent
  isolation, repeated compaction, and a deterministic 60-turn checkpoint
  fidelity fixture.

## Distribution

The release is distributed through signed macOS archives, Linux archives and
packages, Windows worker packages, npm packages with provenance, the Homebrew
tap, VS Code bundle, and Web Operator archive.
