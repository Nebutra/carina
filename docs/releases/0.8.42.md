# Carina 0.8.42

Operator-visible remainder after 0.8.41. Constitution still rode in the
Anthropic user turn, so prefix cache could not hold A–D, and a build-mode
「分析 repo」could answer from product identity without tools.

## Highlights

- Anthropic sends constitution A–D as cached `system` blocks. Workspace
  and catalog sit after the cache boundary. The user turn is TASK,
  transcript, and images. `hi` does not put `You are Carina` in user text.
- Identity and project instructions are not this repository. Session
  dialogue no longer treats referring to the last answer as inspecting
  the workspace.
- `/context` labels `constitution_role` (`system` on Anthropic, `user`
  elsewhere) and does not imply prefix cache on Grok or OpenAI.

## Upgrade notes

- Open `carina` again after upgrading. If a task is still running, wait
  for it to finish first. Carina does not interrupt active tasks
  automatically.
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
- Grok and OpenAI-compatible routes, including Mox, still send the
  constitution as a user blob (`cache=none`). Anthropic is the path that
  now uses `system`.
