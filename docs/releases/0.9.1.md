# Carina 0.9.1

Carina 0.9.1 is a stability patch for the 0.9.0 harness release. It keeps
the same governed browser, durable-job, read-only Git, proactive, registry,
SDK, protocol, and TUI surfaces while making the release gate reliable on
constrained CI hosts.

## Stability fixes

- PTY first-frame benchmarking now reports a clear unavailable result when
  the host temporarily cannot allocate a pseudo-terminal; functional PTY
  failures remain hard failures.
- Daemon tests isolate host model caches so a developer or CI runner cache
  cannot interfere with runtime catalog tests.
- Go race validation runs packages serially to avoid cross-package resource
  contention while preserving the race detector.

## Distribution

The release is distributed through the signed macOS archives, Linux archives
and packages, Windows worker packages, npm packages with provenance, the
Homebrew tap, VS Code bundle, and Web Operator archive.
