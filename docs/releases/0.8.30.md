# Carina 0.8.30

Operator-visible remainder after 0.8.29. This version makes a short daily
chat look like a document instead of a syslog with a signed composer.

## Highlights

- User turns paint the message band only behind occupied cells. A short
  prompt is a pill, not a full-width slab. Selection may still own the row.
- Policy-denied tools recede as settled receipts: no danger rail, no live
  warning title. The status word stays. Real failures keep the failure cell.
- Assistant answers remain unboxed `Reset` body. An extra beat follows an
  answer before thinking, tools, patches, failures, and notices.
- Settled tool titles use muted gray without bold so receipts sit behind
  the answer. Live tools, approvals, and failures keep their rank.
- Leftover transcript height below the last turn is rest, not a fill.

## Upgrade notes

- Restart an active workspace runtime after upgrading so its daemon, kernel
  service, and TUI all load 0.8.30. Carina does not interrupt active tasks
  automatically. Reopen the TUI after the daemon epoch changes.
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
