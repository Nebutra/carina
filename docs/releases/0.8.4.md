# Carina 0.8.4

Patch release on the 0.8 line. Focus: live model inventory for token-backed
proxies and thin catalogs.

## Highlights

### Live model list (`model.list`)

- Runnable OpenAI-compatible, Anthropic, and Gemini providers with a stored
  credential can expand their inventory from the upstream `GET /models`
  endpoint (Bearer / API-key auth).
- Targets thin catalogs and imported routes such as CC Switch / TDS managed
  proxies, which previously projected only the profile default model.
- Short dial/header timeouts, 90s positive and negative cache, and catalog
  fallback when the endpoint is unreachable or returns nothing useful.
- Filters non-chat modalities (embeddings, audio, …); keeps the configured
  default model first even when the live list omits it.

## Upgrade notes

- Restart long-running `carina-daemon` after upgrade so the picker uses live
  discovery under the `0.8.4` runtime.
- Standalone: `carina update`. Homebrew: `brew update && brew upgrade carina`
  after the release workflow updates the tap.
