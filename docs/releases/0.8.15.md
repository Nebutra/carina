# Carina 0.8.15

Patch release. Fix idle Ctrl+C quitting on a single press.

## Highlights

### Double Ctrl+C to quit while idle

- With no active run, the first `Ctrl+C` now primes quit and shows
  “Press Ctrl+C again to quit”; the second press within the grace window exits.
- With an active run, `Ctrl+C` still hard-cancels that run only (does not exit).
- Matches the double-confirm pattern used by Esc Esc history rewind.

## Upgrade notes

- Restart the TUI after upgrade (local binary or `carina update`).
