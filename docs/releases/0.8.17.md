# Carina 0.8.17

Streaming, code-intelligence, and terminal interaction release. This version
keeps provider credentials with their owning CLI, reduces first-use indexing
latency, and presents runtime output as readable product UI instead of protocol
payloads.

## Highlights

### Native streaming and provider ownership

- Claude Code-backed routes now delegate inference and OAuth refresh to Claude
  Code instead of exporting its access or refresh tokens into Carina.
- Claude and Codex routes publish ordered assistant deltas and converge on one
  canonical final answer without repainting the transcript as a late blob.
- Retry routing preserves the model and reasoning choice selected in the TUI,
  while provider readiness distinguishes reusable API credentials from
  CLI-owned sessions.

### Resumable code intelligence

- Large workspaces build one resumable symbol graph in bounded background
  batches instead of blocking the first `code.map` request on a full scan.
- `code.map` projects token-bounded symbols, relationships, hot nodes, and
  provenance so agent context carries useful structure rather than a flat file
  inventory.
- Read, list, search, and code-intelligence calls can settle into one compact
  Explore group while preserving expandable evidence and failure visibility.

### Human-readable final answers

- Structured model reports are projected into readable Markdown sections for
  the transcript while their typed payload remains available to the runtime.
- Partial JSON wrappers stay private during streaming, preventing raw protocol
  documents from flashing before the final presentation is known.
- Retry ancestry keeps one canonical user prompt across attempts without
  merging independent prompts that happen to contain the same text.

### Product menu and interaction geometry

- The stable `Carina` product trigger opens an anchored menu for new
  conversations, conversation history, status, settings, and help.
- Pointer hover, outside-click dismissal, repeated trigger toggling, keyboard
  navigation, and governance-overlay preemption share one typed action path.
- The menu renders below the complete header hairline as an independent
  surface, with equivalent English, Simplified Chinese, Unicode, and ASCII
  geometry.

## Upgrade notes

- Restart each active workspace runtime after upgrading so its daemon, kernel
  service, and TUI all load 0.8.17. Carina does not interrupt active tasks
  automatically.
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
