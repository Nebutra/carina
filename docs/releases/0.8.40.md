# Carina 0.8.40

Operator-visible remainder after 0.8.39. A Grok greeting could fail in
milliseconds because the official model snapshot grew a field Carina did
not allowlist. The card then said to check the network. After install,
TUI users still had to know `carina runtime stop`.

## Highlights

- Grok isolation strips unknown public cache fields and skips unusable
  models. A messy, stale, or credential-bearing snapshot no longer fails
  Think. Secrets are never copied into isolation.
- Failure copy names the local Grok cache and `grok login`, not the
  network.
- Bare `carina` replaces an idle owned daemon whose product version does
  not match this client. `carina runtime stop` stays an operator verb.

## Upgrade notes

- Open `carina` again after upgrading. If a task is still running, wait
  for it to finish first. Carina does not interrupt active tasks
  automatically.
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
