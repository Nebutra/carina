# Carina 0.8.33

Operator-visible remainder after 0.8.32. The first conversation frame should
appear before Grok or live model inventory, listing a workspace should not
walk a thousand files for two hundred lines, and a long Think or tool wait
should stay alive in the UI.

## Highlights

- The TUI paints conversation chrome before `model.list`. Inventory fills in
  after first paint. `tui_bench` now reports PTY TTFF/TTFI.
- `list` is a bounded tree (`--max-files 200 --max-depth 4`), not a full walk
  truncated afterward.
- Parallel `list`/`read`/`search` authorize workspace FileRead once, then fan
  out IO. Grok isolation inspect runs once per process, not every Think.
- Compaction elides and collapses before Think. Model summaries run after the
  turn, not in front of the first token.
- Think and tool waits longer than 1s emit bus-only keepalive. They do not
  write the hash-chained audit log.

## Upgrade notes

- Restart an active workspace runtime after upgrading so its daemon, kernel
  service, native tools, and TUI all load 0.8.33. Carina does not interrupt
  active tasks automatically. Reopen the TUI after the daemon epoch changes.
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
