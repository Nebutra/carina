# Carina 0.8.18

Conversation-header visibility patch. This release makes the selected or
effective reasoning effort visible beside the model without adding another
control to the terminal shell.

## Highlights

- The compact conversation header now renders model and reasoning effort as
  one route, for example `gpt-5.6-sol · high reasoning`.
- The complete model-and-effort label shares one hover and click target that
  opens model settings.
- Narrow terminals hide the route atomically instead of leaving detached or
  partially interactive metadata.
- English, Simplified Chinese, Unicode, ASCII, Plan, Build, product-menu, and
  overlay layouts are covered by production render and PTY regressions.

## Upgrade notes

- Restart an active workspace runtime after upgrading so its daemon, kernel
  service, and TUI all load 0.8.18. Carina does not interrupt active tasks
  automatically.
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
