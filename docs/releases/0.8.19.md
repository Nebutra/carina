# Carina 0.8.19

Runtime routing and terminal navigation patch. This release improves repository
context delivery through proxied providers, clarifies model-picker navigation,
and removes a misleading one-row approximation of the Carina symbol.

## Highlights

- Repository map context is delivered through supported provider capabilities
  without dropping proxy-advertised tools.
- Model settings name and return to the surface that opened them, preserving
  drafts and active review context.
- The one-row conversation header uses the explicit `Carina` product trigger;
  the canonical terminal mark remains reserved for layouts tall enough to
  preserve its silhouette and central counterform.
- Unicode, Nerd Font, ASCII, no-color, provider routing, and model navigation
  paths retain focused regression coverage.

## Upgrade notes

- Restart an active workspace runtime after upgrading so its daemon, kernel
  service, and TUI all load 0.8.19. Carina does not interrupt active tasks
  automatically.
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
