# Carina 0.8.1

Patch release on the 0.8 line. Focus: residual day-one UX iron gates for
ScreenMode clarity and durable follow-up queue inspection.

## Highlights

### ScreenMode operator clarity

- The conversation status line shows the active screen mode token
  (`minimal`, `fullscreen`, or `inline`) without opening help.
- Forced Inline projections surface an explicit reason (zellij, tmux,
  dumb terminal, or capability fallback) instead of degrading silently.
- Mode switches emit a short notice with the target mode and whether native
  scrollback is on or off before re-exec handoff.

### Durable queue inspection

- New operator RPCs `execution.queue.list` and `execution.queue.drop` expose
  truncated previews and stable `steer_id` values for the durable steer queue.
- Full message bodies remain off list/status/metrics surfaces; previews use a
  cell budget so secrets are not dumped into operator chrome.
- The TUI `/queue` overlay lists pending follow-ups for the active run, supports
  drop-by-id, and closes with Esc without hard-cancelling the run.

### Residual UX iron gate

- `make residual-ux-gate` runs focused daemon steer/interrupt/queue tests,
  toolchain hard-cancel coverage, and TUI screen-mode / keybinding / i18n units.
- Soft interrupt, hard cancel, and steer contracts remain distinct; reconnect
  continues to restore durable queue depth from control sidecars.
- Queue list/drop methods are registered in `protocol/jsonrpc/methods.json` so
  the daemon method set stays bidirectionally consistent with the protocol catalog.

## Upgrade notes

- Restart long-running `carina-daemon` processes after upgrading so CLI, TUI,
  and daemon all advertise the `0.8.1` runtime contract.
- Standalone installs can use `carina update`. Homebrew installs use
  `brew update && brew upgrade carina` after the release workflow updates the
  official tap.
- Use `/queue` while a run is active to inspect or drop durable follow-ups.
