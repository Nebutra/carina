# Carina 0.8.27

Hygiene remainder after 0.8.26. This version locks the large-paste chip
width contract and removes leftover phase-roadmap comments.

## Highlights

- The composer paste-chip layout test now runs. Chip width follows
  `paste_chip_line`, not the backing paste payload.
- Worker, scheduler, model-router, and TCP dial comments describe the
  shipped paths. They no longer say streaming or remote workers are still
  "Phase 1/3".

## Upgrade notes

- Restart an active workspace runtime after upgrading so its daemon, kernel
  service, and TUI all load 0.8.27. Carina does not interrupt active tasks
  automatically. Reopen the TUI after the daemon epoch changes.
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
