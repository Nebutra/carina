# Carina 0.8.8

Patch release on the 0.8 line. Focus: full live model lists for CC Switch
profiles such as TDS without a prior auth import.

## Highlights

### CC Switch live model inventory

- Importable CC Switch credentials resolve directly from the local CC Switch
  database (short-lived cache) for inventory and execution.
- Thin profiles (TDS default `gpt-5.5`) expand via authenticated `GET /models`.
- Managed proxy rows are labeled `Name · Proxy` so they do not hide the saved
  profile that shares the same CC Switch display name.

## Upgrade notes

- Restart `carina-daemon` after upgrade, then reopen the model picker for TDS.
- Standalone: `carina update`.
