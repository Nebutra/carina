# Carina 0.8.14

Patch release. More operator-facing honesty after 0.8.10–0.8.13.

## Highlights

### Localized failure and model health reasons

- Execution failure **reason** text localizes (限流/熔断/凭证/推理强度…), not
  only the title.
- Model picker detail reasons use locale copy keyed by status code instead of
  English daemon `status_reason` strings.

### Conservative live-model capabilities

- Live `/models` ids without catalog metadata no longer claim `tool_call`.
- Reasoning is claimed only when a wire effort family exists (so effort Tab
  remains available for CC Switch Codex/Claude/Gemini routes).

## Upgrade notes

- Restart `carina-daemon` and relaunch the TUI after upgrade.
- Standalone: `carina update`.
