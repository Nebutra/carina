# Carina 0.8.11

Patch release on the 0.8 line. Fixes two operator-facing regressions from the
0.8.9–0.8.10 model-picker work.

## Highlights

### Reasoning effort on CC Switch / Codex / Azure routes

- `applyNativeReasoningEffort` encodes by **effort family** (not bare provider
  id). `ccswitch-codex-*`, Azure, OpenRouter, and xAI routes that already show
  effort ladders in the model picker now send `reasoning.effort` on the wire.
- CC Switch Gemini family routes encode `thinkingLevel` the same way as Google.
- Prevents the local failure: `reasoning effort is not supported by this adapter`
  after selecting low/medium effort on Mox/TDS Codex models.

### Provider list status no longer clips CJK

- Right-hand status column width uses terminal **cell** width instead of char
  count, so labels like 「就绪」 render fully instead of truncating to 「就」.
- Action buttons (使用模型 / 使用此服务商 / 打开) use the same cell-width math.

## Upgrade notes

- Restart `carina-daemon` and relaunch the TUI after upgrade.
- Standalone: `carina update`.
