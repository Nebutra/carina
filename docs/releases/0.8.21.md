# Carina 0.8.21

Import presentation and updater-fixture follow-up. Conversation import itself
shipped in 0.8.20; this tag keeps those receipts readable in ASCII/Unicode
terminals and keeps standalone updater fixtures ahead of the product version.

## Highlights

- Import snapshots pin to the Unicode glyph set so receipts stay aligned when
  a terminal cannot render the operator's preferred symbol tier.
- Release updater fixtures stay ahead of the product version so `carina update`
  checks remain valid after the 0.8.20 import tag.

## Upgrade notes

- Restart an active workspace runtime after upgrading so its daemon, kernel
  service, and TUI all load 0.8.21. Carina does not interrupt active tasks
  automatically.
- Conversation import behavior is unchanged from 0.8.20: it is an explicit
  point-in-time copy, not background sync.
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
