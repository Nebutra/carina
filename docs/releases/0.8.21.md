# Carina 0.8.21

Conversation import release. This version lets teams bring useful Claude Code
and Codex history into Carina as attributed local copies, continue from that
context safely, and keep the original harness data untouched.

## Highlights

- The conversation browser now includes an `Import conversations` workflow
  with source selection, current-workspace discovery, preview, multi-select,
  confirmation, and exact import receipts.
- `carina import list` and `carina import apply` expose the same Claude Code and
  Codex workflow for terminals and automation, including JSON output and
  explicit source-root overrides.
- Imported conversations retain source labels and durable provenance. Repeating
  an unchanged import creates no duplicate session or messages; checking again
  after the source grows imports only the new visible messages.
- Source files are read locally and never modified. Imported text is bounded
  and treated as untrusted historical context, while external tool calls,
  hidden reasoning, approvals, and system instructions never become Carina
  execution or authority records.
- English and Simplified Chinese product guidance explain where import lives,
  what gets copied, and how explicit re-import differs from background sync.

## Upgrade notes

- Restart an active workspace runtime after upgrading so its daemon, kernel
  service, and TUI all load 0.8.21. Carina does not interrupt active tasks
  automatically.
- Conversation import is an explicit point-in-time copy. Use `Import again` or
  check for new conversations when source history changes; this release does
  not add background or bidirectional synchronization.
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
