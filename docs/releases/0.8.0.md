# Carina 0.8.0

Minor release focused on terminal-native interaction, durable execution
control, deterministic context collapse, and honest multi-session resource
observability.

## Highlights

### Minimal by default, with explicit review modes

- The TUI now has first-class `minimal`, `fullscreen`, and `inline` screen
  modes over one shared semantic state model.
- Minimal mode commits finalized transcript blocks once to native terminal
  scrollback while retaining the live tail, composer, and overlays.
- Fullscreen mode owns mouse, focus, graphics, and alternate-screen review;
  Inline is the keyboard-only fallback for SSH and capability-poor terminals.
- Mode switches re-exec and reconnect with a bounded, identity-fenced handoff
  that preserves the session, draft, follow-up queue, selection, governance
  state, transcript position, and native-scrollback watermark.

### Soft interrupt and durable steering

- `Esc` requests a soft pause at the next safe point while `Ctrl-C` remains a
  distinct hard cancellation path.
- Steers and follow-ups use a durable, bounded urgent/normal FIFO with stable
  idempotency keys and explicit acknowledgement after transcript and
  checkpoint persistence.
- Paused executions retain queued follow-ups; terminal executions clean their
  control state; resume clears stale interrupt intent without dropping steers.
- `/keymap` exposes the actual terminal-family bindings, including Ghostty and
  VS Code send-now behavior and idle double-Esc checkpoint history.

### Deterministic collapse and resource evidence

- Normal context pressure uses a local `collapse_only` tier that preserves
  verbatim user content and critical evidence without invoking a summarizer.
- Severe pressure still uses model summary, and compaction receipts record the
  selected mode and deterministic transforms while remaining compatible with
  older receipt versions.
- Doctor and metrics surfaces report real Linux RSS when available, Go heap,
  session/task/run/checkpoint/compaction counts, checkpoint bytes, and artifact
  cache counters without invented PSS or per-session RSS attribution.

### Terminal polish and resilience

- Active status copy now distinguishes safe pause from hard cancellation and
  keeps the pause, follow-up queue, elapsed time, and measured context I/O
  visible together at supported widths.
- Reduced-motion mode removes decorative redraw deadlines and uses static,
  width-stable Unicode and ASCII glyphs.
- PTY coverage now certifies Ghostty, iTerm, WezTerm, SSH, tmux, VS Code,
  `NO_COLOR`, and `TERM=dumb`, with CJK cell geometry and narrow layouts kept
  within their owned regions.

## Upgrade notes

- Restart long-running `carina-daemon` processes after upgrading so the CLI,
  TUI, daemon, integrations, and SDK compatibility checks all advertise the
  `0.8.0` runtime contract.
- Bare `carina` now starts in Minimal mode. Use `/fullscreen` for long review
  surfaces or `carina --screen-mode fullscreen`; `--no-alt-screen` remains a
  Minimal compatibility shortcut.
- Standalone installs can use `carina update`. Homebrew installs use
  `brew update && brew upgrade carina` after the release workflow updates the
  official tap.
