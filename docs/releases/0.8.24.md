# Carina 0.8.24

Operator-visible remainder after 0.8.23. This version makes isolated CLI
handshakes and provider retries tell the truth, shows compaction as a
replayable transcript cell, and keeps goal auto-continue inside the current
daemon so a restart cannot steal a run.

## Highlights

- Isolated Grok Build accepts a boolean or null `consent_gate`. Claude
  thinking-then-text assistant snapshots no longer fail as protocol errors.
  Exhausted provider retries name the attempt count and stay retryable.
- Failure cells show `max(execution lineage, provider_attempts)`, so four
  HTTP 503s read as four tries instead of one.
- `ContextCompacted` receipts become `compact:{event_id}` cells on live and
  replay transcripts. Request-only and identity-engine events stay off the
  transcript; `engine=noop` never claims savings.
- Stale or unreadable Grok `models_cache.json` is skipped during isolation
  setup instead of aborting the first think with a generic configure error.
- `auto_continue` is process-local. It is never written to `goals.json` and
  is cleared on load. Restart does not mark a goal complete or submit another
  continuation.

## Upgrade notes

- Restart an active workspace runtime after upgrading so its daemon, kernel
  service, and TUI all load 0.8.24. Carina does not interrupt active tasks
  automatically. Reopen the TUI after the daemon epoch changes.
- Re-arm unattended goal continuation with `goal.set` (`auto_continue: true`)
  or submit an explicit `goal.continue`. A persisted `active` goal is not
  enough after restart.
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
