# Carina 0.9.4

Carina 0.9.4 is a focused TUI correctness release.

## Transcript privacy

- Keeps `PromptCacheObserved` receipts as audit-only operational telemetry.
- Prevents the generic transcript classifier from treating the `Prompt`
  substring in that event type as evidence of a user message.
- Removes repeated `Boundary`, `Cache kind`, `Evidence`, and `Model` metadata
  blocks from live conversations while preserving cache receipts for audit and
  release SLO measurement.

## Verification

- Adds a Rust transcript reducer regression covering repeated live cache
  receipts.
- Preserves durable session hydration behavior, which already excludes prompt
  cache telemetry from conversation items.
