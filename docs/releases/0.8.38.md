# Carina 0.8.38

Operator-visible remainder after 0.8.37. Greeting turns still busted the
skill prefix cache, native HTTP restated the JSON catalog, compact forgot
cited files, and search/list dumped raw grep/trees. Plan mode advertised a
checklist that did not dispatch, and the open web still required a URL
before `web.fetch`.

## Highlights

- `todo` / `update_plan` are real session checklist tools (dispatch + schema).
  Plan mode allows them; explore does not.
- `web.search` is a governed public-web query (host approval, untrusted,
  fail-closed). Use it before `web.fetch`. Never `run`/`curl`.
- REQUESTED skills and SKILL WARNING sit in the volatile suffix. Catalog
  cache no longer depends on greeting wording. Native tools use a ≤200 B
  envelope and do not re-paste `toolsHelp`.
- After compact, ≤5 cited files rehydrate into the transcript (8k cap).
  Search/list observations are path + why, not 50-line dumps.
- Provider-reported input tokens drive model-view pressure when present;
  `len/4` remains the fallback. `go/contextengine` stays identity.

## Upgrade notes

- Restart an active workspace runtime after upgrading so its daemon, kernel
  service, native tools, and TUI all load 0.8.38. Carina does not interrupt
  active tasks automatically. Reopen the TUI after the daemon epoch changes.
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
