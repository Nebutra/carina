# Carina 0.8.7

Patch release on the 0.8 line. Focus: Fullscreen is the default TUI surface.

## Highlights

### Fullscreen by default

- Bare `carina` launches in **Fullscreen** (alt-screen + mouse capture) so
  trackpad/wheel scrolling stays inside Carina instead of terminal history.
- **Minimal** remains available for operators who want native scrollback:
  `/minimal`, `--screen-mode minimal`, or `--no-alt-screen`.
- Weak multiplexers (Zellij / control-mode hosts) still force **Inline** for
  capability safety.

## Upgrade notes

- Restart the TUI after upgrade to pick up the new default (`Esc`/`q` out, then
  `carina` again). A long-running TUI process keeps the mode it started with.
- Standalone: `carina update`. Homebrew: `brew update && brew upgrade carina`
  after the release workflow updates the tap.
