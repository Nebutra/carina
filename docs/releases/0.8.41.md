# Carina 0.8.41

Operator-visible remainder after 0.8.40. A second Grok turn could fail
because persist ACP treated a session title notification as an unsafe
turn event. The model picker then showed only the proxy default as
having image and tools, even when models.dev already knew the siblings.

## Highlights

- Persist Grok ACP absorbs session-scoped `session_summary_generated`
  leftovers instead of failing Think. Failure copy names Grok isolation,
  not a generic turn.
- Live proxy inventories inherit image and tool chips from the canonical
  lab catalog. Unknown ids stay fail-closed. The media gate uses the same
  lookup.

## Upgrade notes

- Open `carina` again after upgrading. If a task is still running, wait
  for it to finish first. Carina does not interrupt active tasks
  automatically.
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
