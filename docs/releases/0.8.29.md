# Carina 0.8.29

Operator-visible remainder after 0.8.28. This version makes the conversation
surface look designed instead of like a typed log.

## Highlights

- An empty conversation shows the product mark, name, and one operating hint.
  ASCII and short panes keep the name and hint without the mark.
- The composer is an open-sided field: top and bottom rails, no side walls.
  Live run, queue, and approval-wait copy sit in the top rail.
- The conversation header keeps model identity and drops reasoning telemetry.
- Live tools, thinking, approvals, and failures own a one-cell accent rail.
  Settled tools recede.
- Approvals use warning chrome instead of a red room. Failure actions render
  as `[ Retry ]` chips.
- Live thinking replaces disclosure with a width-locked spinner that shares
  the composer activity clock. Reduced motion freezes the first frame.
- `/theme` and Settings preview `auto`, `dark`, and `light` live. Enter saves
  `tui_theme`; Esc keeps the previous choice. This is not a theme catalog.

## Upgrade notes

- Restart an active workspace runtime after upgrading so its daemon, kernel
  service, and TUI all load 0.8.29. Carina does not interrupt active tasks
  automatically. Reopen the TUI after the daemon epoch changes.
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
