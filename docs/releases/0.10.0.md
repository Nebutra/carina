# Carina 0.10.0

Carina 0.10.0 introduces the production Web and Tauri Harness surfaces for
running and inspecting governed local agent sessions.

## Harness clients

- Replaces the legacy static Web Operator with a Vite 8, React 19, and
  TypeScript application built from project-owned design-system primitives.
- Shares the same React surface with native Tauri clients on macOS and Linux.
- Adds workspace selection, bounded image attachments, session navigation,
  file and terminal panels, and an authoritative trajectory inspector backed
  by daemon session events.
- Adds keyboard focus handoff, mobile off-canvas navigation, reduced-motion
  behavior, semantic connection announcements, and persistent non-sensitive
  interface preferences.

## Local Gateway ownership

- Adds `carina harness bootstrap` to start or reuse an owner-controlled,
  loopback-only Gateway and issue a short-lived scoped browser token.
- Pins browser origin, workspace tenant, role, transport, and optional session
  identity at the daemon boundary.
- Keeps token issuing off the remote Web surface and stores desktop bootstrap
  credentials only in React memory.
- Uses bounded reconnect backoff for network failures while authentication,
  role, and schema failures remain fail-closed.

## Packaging and verification

- Publishes signed and notarized macOS DMGs plus Linux AppImage and Debian
  bundles for arm64 and amd64. Windows remains a remote-worker target; no
  Windows desktop Harness is claimed in this release.
- Adds Tauri package integrity checks, owner-bridge unit tests, Web browser
  journeys, and exact 44-asset immutable-release verification to CI and release
  gates.
