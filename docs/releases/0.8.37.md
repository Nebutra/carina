# Carina 0.8.37

Operator-visible remainder after 0.8.36. Every Grok/OpenAI turn was still
paying a thousand-token tool catalog, Anthropic cached one constitution blob,
and the public product still called itself a runtime.

## Highlights

- Live constitution (no Workspace/F) stays under 800 tok: one-line builtins,
  five standing protocol bullets, JSON examples only in tests.
- Constitution is a named list (Mode, Identity, Protocol, Tools). Anthropic
  attaches `cache_control` per A–D section (API cap 4). Grok still receives
  `full()` with cache kind `none`.
- Product copy is **Carina Harness**, not Carina Runtime. `carina runtime`
  remains the workspace-daemon CLI.

## Upgrade notes

- Restart an active workspace runtime after upgrading so its daemon, kernel
  service, native tools, and TUI all load 0.8.37. Carina does not interrupt
  active tasks automatically. Reopen the TUI after the daemon epoch changes.
- Local source installs can run `make install`; packaged installs can use
  `carina update`, Homebrew, npm, or the release archive.
